v0.3.0 2026-05-11 已发布

支持 Claude Code 啦，并重做记忆系统

0.3.0 是 OpenRelix 记忆体系的一次大整理：它会更谨慎地挑选该注入给 AI 的记忆，也把 Claude Code、多 Codex Home、资产热度、Token 和 Pipeline 状态都收进同一个面板里。

新功能
  • 记忆注入 v2：统一 host memory context，按项目、证据和预算挑记忆；不该带进来的项目记忆不会轻易混进当前上下文。
  • Claude Code 接入：支持读取 Claude Code 的项目记忆，面板里能分清 Claude / Codex 原生记忆和 OpenRelix 注入记忆。
  • 多环境支持：可以同时管理多个 Codex Home / 桌面 Profile，运行中的 profile 能复用，resume 路由也更准确。
  • 资产发现与热度：自动发现技能、提示词、Rules、插件、启动项，并用真实 LLM 激活频率和技能读取次数判断哪些资产真的常用。
优化
  • Token 面板加了 provider、日期、月维度筛选，默认看近 7 天；月统计、cache write 和空闲日期零值口径也一起修顺。
  • Pipeline 面板能看到运行状态、历史记录、完成状态和下次运行时间，历史数量也做了限制，不再越积越乱。
  • Project / Window Overview 重做：过滤器联动、日期选择器、sticky filters、窗口 hover 详情和项目数量限制都补齐。
  • Asset 面板加了刷新控件、自动刷新、相对刷新时间和更轻量的统计卡片，看状态更直接。
修复
  • 安装 / 更新更稳：更新入口改为强制重装 worker，installer 会主动执行必要的 memory migration / backfill，并用迁移版本避免旧数据卡住。
  • 记忆质量门禁更严：新增 evidence gate 和轻量 summary 标注，降低低质量记忆被带进上下文的概率。
  • 面板反馈和 Native Memory 展示修正：反馈控件更快更稳，重复 host memory bullet 被清掉；Native Memory 视图隐藏注入记忆，保留 Codex native summary。
  • 窗口计数忽略 Claude tool events，Claude windows 可以直接打开到桌面 app，减少“看起来多算了一堆窗口”的错觉。

v0.2.0 2026-04-29 已发布

桌面端来了，面板会自己提醒升级

v0.1 系列之后的第一次 minor 升级。OpenRelix 不再只是命令行——它现在是个能在 Launchpad 里搜到的 macOS app，并且会在右下角小声提醒你「有新版了」。

新功能
  • macOS 桌面端：真实 app bundle 自动同步到 ~/Applications/OpenRelix.app，Launchpad / Spotlight / Finder「应用程序」更稳定可发现，不用再翻终端
  • 面板内自动检查新版本：右下角飘个小药丸告诉你有新版可升，客户端面板可以一键执行 openrelix update --yes（走本地 Token 校验 + file:// 来源限制，杜绝公网页面摸进来）；浏览器端没有本地权限，降级为帮你把 npm update -g openrelix 复制到剪贴板
  • 安装 / 更新结束后会主动问你两句：要不要现在就学一下最近 7 天的记忆（5–30 分钟）？要不要顺手打开客户端？不想被问就加 --no-learn / --no-launch，CI 和非交互终端自动跳过
优化
  • codex-native 中文渲染规则全部搬到 <state_root>/personal_codex_rules.py，仓库引擎不再带任何示例数据；升级后少数原生记忆话题会回退到英文原文，需要的话自己往个人规则文件里加就回来了
  • 加了发布前 personal-info 自动检查：CI 卡口 + 可选本地 pre-commit hook，扫描跟踪文件里的用户路径 / 个人邮箱 / 硬编码凭据，以及你自己写的 <state_root>/personal_denylist.txt 模式
  • 安装时语言选择的中英文提示都强调了一遍：选完之后 UI、本地记忆、模型生成内容会一起锁定语言，事后想切得重装并清空记忆
  • 面板上 Token 账单做了四舍五入，不再拖一长串小数
  • 发布流程切到 npm trusted publishing GitHub Actions，少踩一步手动 token 的雷
修复
  • 修了一个隐蔽但影响很大的坑：后台 LaunchAgent 跑 nightly 时找不到 codex 二进制，被迫回退到 history 模式，结果 VS Code 扩展和那些只活在 app-server 里的对话整窗口丢失。现在 plist 会注入 CODEX_BIN 和安全 PATH，老用户也兜底，fallback 路径扩展到 volta / bun / nvm
  • review 刷新完面板会跟着更新输出了，不再卡着旧数据
  • Token 实时刷新后账单不再错位

v0.1.0 2026-04-28 首发

OpenRelix 公开预览版首发

跑通本地优先个人 AI 资产系统的最小完整闭环：把每天和 AI CLI 一起做过的工作沉淀成可复用的技能、模板、自动化、记忆和可视化复盘，而不是散落在聊天记录里。

核心能力
  • 一键 npm 安装与 install 脚本，覆盖 macOS 默认目录布局
  • Codex CLI 与 Codex app-server 工作窗口采集，本地优先
  • 任务复盘、资产登记、长期/工作记忆分层
  • 面板可视化：日摘要、关键指标、Token 信号
  • macOS LaunchAgent 后台自动化（每 1 小时刷新、深夜固化）
边界与隐私
  • 仓库只放可复用能力（安装器、技能、模板、自动化脚本、文档）
  • 个人状态默认写到独立状态目录，不进入 npm 包和源码仓库
  • 密钥、Token、Cookie、原始内部日志不进入资产库与公开预览
相关提交

  • 整理为 OpenRelix 公开预览版 (bb2e91e)
